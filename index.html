PubMed Reading List Builder

Search PubMed, pick the articles you want, and export them for EndNote, Zotero, or a spreadsheet.

This page needs the server to work. Start it with python server.py, then open http://127.0.0.1:8000. Opening the file directly won't connect to PubMed.
Search terms are sent to NCBI PubMed through this server. If you use the AI query helper, what you type there is sent to the AI provider the server is set up with. Do not enter patient data or other protected health information. Always verify citations against the publisher or PubMed before using them.

Query helper (AI Gemini/Anthropic)

Describe your topic in plain language. The helper suggests a PubMed query, and this page checks it against PubMed. AI can be wrong, so review every query.

Supports PubMed syntax: MeSH terms, [tiab] fields, AND / OR / NOT, and quotes.
Article type (optional)
Checking several types returns articles matching any of them.
